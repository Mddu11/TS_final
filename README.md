# Personal Finance Manager

Консольное приложение на TypeScript для управления личными счетами и транзакциями. Все меню, запросы и подтверждения выполняются с помощью библиотеки **Inquirer**.

## Возможности

- просмотр списка счетов;
- создание счёта с уникальным UUID;
- просмотр транзакций и баланса выбранного счёта;
- добавление доходов и расходов с проверкой суммы, даты и категории;
- удаление транзакций с подтверждением;
- удаление счёта вместе со всеми его транзакциями с подтверждением;
- экспорт транзакций счёта в CSV;
- сохранение счетов и транзакций между запусками в `data/accounts.json`.

## Требования

- Node.js 20 или новее;
- npm (устанавливается вместе с Node.js).

Проверить установку можно командами:

```bash
node --version
npm --version
```

## Установка и запуск в VS Code

1. Открой папку `finance-manager` в VS Code.
2. Открой терминал: **Terminal → New Terminal**.
3. Убедись, что терминал открыт в корневой папке проекта, где находится `package.json`.
4. Установи зависимости:

   ```bash
   npm install
   ```

5. Запусти программу в режиме разработки:

   ```bash
   npm run dev
   ```

Для проверки компиляции TypeScript выполни:

```bash
npm run build
```

После успешной сборки приложение можно запускать так:

```bash
npm start
```

## Как пользоваться

1. В главном меню выбери действие стрелками на клавиатуре и нажми Enter.
2. Создай счёт, затем открой его через пункт выбора счёта.
3. В меню счёта добавляй или удаляй транзакции и экспортируй данные в CSV.
4. При удалении счёта или транзакции приложение запрашивает подтверждение.
5. Чтобы закончить работу, выбери «Выход» в главном меню.

Сумма вводится числом больше нуля. Для дробной части используй точку, например `1250.50`. Доход увеличивает баланс, расход уменьшает его. Дата вводится в формате `ГГГГ-ММ-ДД`, например `2026-10-16`.

## Где хранятся файлы

- `data/accounts.json` — счета и транзакции. Этот файл создаётся автоматически при первом сохранении.
- `exports/` — созданные CSV-файлы. В CSV включены заголовки и транзакции выбранного счёта.
- `src/` — исходный код TypeScript.

Сгенерированные данные пользователя исключены из Git через `.gitignore`.
